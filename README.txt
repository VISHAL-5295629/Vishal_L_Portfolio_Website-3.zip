# Vishal L. Portfolio

A responsive static portfolio website.

## Preview locally
Open `index.html` in a web browser.

## Publish as a live link with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `vishal-portfolio`.
2. Upload `index.html` and `vishal-photo.png` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for deployment. GitHub will show your public website URL in the Pages section, typically:
   `https://vishal-5295629.github.io/Vishal_L_Portfolio_Website-3.zip/`

Check that the published website loads and all links work before submitting the URL on a form.
